# Android / iOS 功能一致性清单

这份清单以当前 iOS 源码为事实来源，而不是以旧需求文档或猜测为准。

- `[x]`：Android 已实现，并至少通过当前可运行的自动检查。
- `[ ]`：仍缺实现、外部配置或真机验证，不能作为已经完成对外承诺。
- “图片附件”和“邀请”已从旧清单删除：当前 iOS 没有照片选择/图片附件入口，也没有邀请功能。iOS 富文本代码中的 `NSTextAttachment` 只用于清单勾选框显示。
