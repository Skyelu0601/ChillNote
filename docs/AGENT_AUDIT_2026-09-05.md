# Agent 指令与工作流审计

审计日期：2026-09-05。目标模型：GPT-6 Astra。

## 官方依据

- [GPT-6 Astra 使用指南](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6-astra)：核对了主动完成任务、指令敏感性、表达、委派与适度验证建议。
- [AGENTS.md 加载机制](https://learn.chatgpt.com/docs/agent-configuration/agents-md)：项目约定分层维护，使用标准文件名，子目录补充局部要求。
- [技能编写与发现](https://learn.chatgpt.com/docs/build-skills)：精确描述触发范围，按需加载正文与参考资料。
- [Codex 最佳实践](https://learn.chatgpt.com/guides/best-practices)：保持指令简短准确，按任务选择上下文、验证与推理设置。

以下是针对本仓库的落实方式，不是官方规定的唯一模板，也不代表性能基准结果。

## 范围

扫描了隐藏及被忽略目录中的指令文件，跳过依赖、构建输出和 Git 内部文件。找到 6 个 `AGENTS.md`、1 个插件 `SKILL.md`、1 个 GitHub Actions 工作流和 1 个 Codex 环境配置。未找到额外的 `agent.md`、`AGENTS.override.md`、`.agents/skills` 或 `.agent/workflows`。

同时检查了根 README、项目背景、国际化规则、外联规则、脚本说明及相关命令入口。`store/app-store/` 是独立工作区，本次未修改其内容。

用户级 `~/.codex/skills`、插件缓存、宿主系统指令和全局模型配置不属于当前仓库；本次仅使用官方文档与技能编写工具，没有批量修改或卸载它们。仓库插件通过 `plugin.json` 的 `skills` 路径分发，保留该路径，不复制到 `.agents/skills` 造成重复技能。

## 发现与处理

| 发现 | 调整 | 保留的约束 |
| --- | --- | --- |
| 根指令未明确日常实现的自主范围 | 在已有授权内继续实现与验证；要求真正阻塞的技能说明出处 | 兼容标识迁移仍需说明影响并明确确认 |
| 品牌、兼容与国际化规则在父子指令重复 | 共用规则留在根文件，子目录保留特有要求 | 签名、OAuth、共享后端与官网边界 |
| 验证清单未说明适用场景 | 各平台按文案、代码、协议或 UI 变更选择检查 | 相关测试、构建与失败披露 |
| 国际化文档重复多轮相同规则，默认要求 iOS 构建 | 188 行压缩为 32 行，分清 iOS 和 Android 入口，验证命令回到平台指令 | 语义化 key、完整语言、模板、复数、权限描述 |
| 外联 AGENTS 重复已强制读取的业务规则 | 改为引用唯一业务规则源，并补充本地验证入口 | 发送确认、付费确认、权益审核、暂停恢复及历史记录 |
| 插件技能每次都加载完整连接说明 | 缩短触发描述，连接与服务错误说明移到按需引用 | 用户隔离、真实 ID、分页、来源引用、只读能力与不可信内容处理 |
| iOS 命令绑定固定设备与系统版本 | 平台指令、根 README 和 Codex 构建动作统一使用通用模拟器编译目标 | 测试和交互验证仍选择实际可用设备，不把编译视为测试 |
| CI 连续提交时重复执行旧任务 | 同一 PR/分支取消过时任务，增加 10 分钟超时 | 保留工作流名、任务名、触发条件、只读权限及全部原有检查步骤 |
| README 把工具目录一概视为可删缓存 | 改为先检查内容与重建方式 | 人工记录与指令不因目录名被误删 |

没有增加每次都要写计划、强制多代理、固定最高推理强度或必须全端测试的要求。委派继续服从宿主能力与授权；这些设置需要具体任务证据，不能仅凭“最大化性能”一律开启。

## 效果与边界

原有 10 个目标文件的正文从 12,154 字符降至 9,308 字符，减少 23.4%；计入新增的 663 字符连接参考文件后仍减少 18.0%。这是字符统计，不是 token、延迟或质量测量。连接参考文件仅在相关任务读取；本报告不属于默认指令入口。

静态场景复核覆盖了：Android 文案不再要求 iOS 构建、普通文档改动不默认全端测试、接口变更仍检查移动端兼容、外联预览与真实发送分开、已连接笔记查询不重复加载 OAuth 步骤。该复核验证指令表达，未运行独立模型行为评估。

实际收益应在后续相同模型与推理设置下，对比代表性任务的完成率、无必要确认次数、重复检查次数、耗时和 token。此次没有进行任务 A/B 测试，因此不宣称已达到最大性能或量化提速。
